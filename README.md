# gitSrch

gitSrch - CLI-инструмент на Go для поиска строки во всех ветках Git-репозиториев.

Подходит для случаев, когда нужно найти:

- TODO / FIXME
- старые конфиги
- использование API
- любой текст в истории проекта

Работает сразу по нескольким репозиториям и поддерживает параллельный поиск.

## Сборка
```sh
go build -o gitSrch main.go
```

Установка для текущего пользователя
```sh
mkdir -p ~/bin
cp gitSrch ~/bin/
export PATH="$HOME/bin:$PATH"
```

## Использование
```sh
gitSrch "search_string" [path] [flags]
```

Поиск в текущей директории
```sh
./gitSrch "artifactoryUpload" \
    ~/some-dir \
    --max-workers 20 \
    --spinner \
    --branch-pattern "master|^rel/.*"
```

| Флаг               | Описание                                   | По умолчанию |
| ------------------ | ------------------------------------------ | ------------ |
| `--max-workers`    | Максимальное количество параллельных задач | 10           |
| `--spinner`        | Показывать крутилку                        | false        |
| `--branch-pattern` | Regex для фильтрации веток                 | ""           |
